게임 운영 관리

학생들의 게임 기록을 살펴보고 운영할 수 있습니다.

첫 관리자 비밀번호 설정

처음 한 번만 Cloudflare에 등록한 ADMIN_KEY를 입력하세요. 이후에는 새로 정한 짧은 비밀번호로 로그인합니다.

영문과 숫자를 포함해 8~64자로 설정하세요. 기존 ADMIN_KEY를 계속 외우실 필요는 없습니다.

관리자 로그인

설정하신 관리자 비밀번호를 입력하세요.

5회 연속 틀리면 15분 동안 로그인이 제한됩니다. 비밀번호를 잊으셨다면 Cloudflare 관리자에게 문의하세요.

운영 현황

—총 참가자
—저장된 기록
—시작된 게임

관리자 비밀번호 변경

영문·숫자 포함 8~64자. 변경하면 다른 기기의 관리자 로그인이 해제됩니다.

최근 게임 기록

닉네임게임모드점수층수기록 시각(UTC)관리

기록 삭제는 되돌릴 수 없습니다. 현재 버전의 점수 검증은 기본적인 범위·시간 검사입니다.

등록된 게임

공개 여부와 순서를 변경하면 게임 포털에 바로 반영됩니다. 비공개로 변경해도 기존 점수는 삭제되지 않습니다.

새 게임 등록

게임 파일은 먼저 GitHub의 public/games/게임ID/에 배포해야 합니다. 이 화면은 게임 정보를 등록하는 곳이며 HTML 파일 업로드 기능은 아닙니다. 온라인 랭킹은 게임별 서버 검증을 구현한 작품에서만 지원됩니다.

게임 실행 주소에 사용하며 등록 후 변경할 수 없습니다.
공개하면 사이트 게임 목록에 표시됩니다. 미배포 파일이 없는지 반드시 확인하세요.
